# Classes

Класс анықтамалары: `ClassDefinitions.lua` (жалпы интерфейс) + `Warrior.lua`, `Archer.lua`, `Mage.lua`, `Assassin.lua`.
Әр модуль stats (HP, урон, жылдамдық) және abilities кестесін қайтарады. Тек деректер мен таза функциялар — RemoteEvent/DataStore шақыруы жоқ (оларды Server қабаты орындайды).
